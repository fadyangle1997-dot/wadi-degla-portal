# أكاديمية عمليات وادي دجلة — معمارية النظام (v0.1)

> **المبدأ الحاكم:** الكود بيتبع التوثيق، مش العكس. أي قاعدة عمل ليها **مكان واحد فقط** في الكود.

## ليه المعمارية دي؟

المشكلة اللي كانت في النسخة القديمة: قاعدة العمل الواحدة (مثلاً غرامة الانفصال) كانت مكتوبة في 4 أماكن (الدرس + مركز المعرفة + التحدي + المحاكي). أي تعديل كان لازم يتعمل 4 مرات، وسهل يحصل تناقض. المعمارية دي بتحل ده جذريًا.

## الطبقات (Layers)

```
src/
├── domain/                 ← قلب النظام (مستقل عن الواجهة تمامًا)
│   ├── types/              ← الأنواع القوية (money, content)
│   └── rules/              ← محرك القواعد — كل حساب معزول ومتختبر
│       └── __tests__/      ← اختبارات تثبت الأمثلة المعتمدة (1342، 6500...)
├── content/                ← المحتوى كبيانات (data)، مش كود
│   ├── modules/            ← كل وحدة = ملف data
│   └── schema/             ← أشكال البيانات
├── lib/                    ← أدوات مشتركة
└── (features/ · ui/)       ← الواجهات (المراحل الجاية)
```

## القرارات المعمارية (Architecture Decisions)

### 1. المحتوى كبيانات (Content as Data)
الدروس والأسئلة والتحديات والرحلة = **بيانات typed** (`domain/types/content.ts`)، والواجهة بترسم اللي البيانات بتوصفه. النتيجة: تقدر تعدّل درس أو تضيف وحدة **من غير ما تلمس كود واجهة**. ده بيفتح الباب إن حد غير مبرمج يحرّر المحتوى مستقبلًا.

### 2. محرك القواعد المعزول (Isolated Rules Engine)
كل حساب مالي = **دالة نقية (pure function)** في `domain/rules/`، بتاخد input typed وبترجّع `CalculationResult` (فيه total + تفصيل بند-بند + شرح بالمصري). مفيش أي حساب مالي جوه أي component. النتيجة: مستحيل رقم يطلع غلط بسبب تعديل في الواجهة، وكل قاعدة متختبرة لوحدها.

### 3. مصدر حقيقة واحد (Single Source of Truth)
- الجداول المالية (تجديد التابع) في مكان واحد: `childJoining.ts`.
- السياسات النصية (الإلغاء، الـScan، الأرشيف) كـconstants في `rules/index.ts`.
- الدرس بيشير للقاعدة بـ`rule` ref بدل ما يعيد كتابتها.

### 4. القرارات المعتمدة الأخيرة مدمجة من الأساس
- **التجديد:** مرحلتين (5% جوه السنة · شرائح 50/100/200/300% بعد السنة · سقوط بعد 5 سنين).
- **الإلغاء:** 30 يوم بدون أسباب.
- **تسجيل المحافظات:** مستبعد بقرار إداري (مش موجود في المحتوى).

## بوابة الجودة (Quality Gate)
- `npm run typecheck` → صفر أخطاء (TypeScript strict).
- `npm run test` → كل الاختبارات خضراء (بتثبت الأرقام المعتمدة).
- أي قاعدة جديدة لازم يتكتبلها اختبار قبل ما تتحسب مكتملة.

## قابلية التوسّع (v5 من دلوقتي)
الأنواع مصمّمة تدعم «أكاديميات ×أقسام ×فروع ×أندية» لاحقًا من غير إعادة بناء — الوحدات بيانات، والقواعد معزولة، والواجهة عامة.

## استرجاع المشروع (أهم نقطة)
المشروع **قابل لإعادة التوليد بالكامل** من: هذا التوثيق + `docs/business-rules.md` + ملفات المحتوى. لو الكود ضاع، بيتبني تاني من المصدر الموثّق.

**قاعدة العمل من دلوقتي:** بعد كل تسليم، احفظ فولدر `src` عندك (مش بس ترفع الـbuild).
