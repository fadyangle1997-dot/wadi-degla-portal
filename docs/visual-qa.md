# الجودة البصرية — إزاي نقيس قبل وبعد

الهجرة البصرية بتتقاس، مش بتتوصف. فيه أداتين في الريبو، والاتنين بيتشغّلوا بأمر واحد.

## 1) الصور والمقاييس: `scripts/visual/`

```bash
npm run build
npm run visual:capture                      # visual-out/<hash>/
npm run visual:capture -- visual-out/after  # أو مكان تختاره
npm run visual:compare -- visual-out/before visual-out/after visual-out/compare
```

- **السيناريوهات:** رحلة المتدرب كلها — الدخول، والترحيب، والرئيسية (يوم 1، ويوم 43، ومستني المدرب، وبعد الاعتماد)، والدرس (أوله، وتاني خطوة، والختام)، والامتحان (السؤال، والرد، وما عدّاش، وعدّى)، والتحدّي (الملف، والقرار، والرد، والنتيجة)، ومراجعة اليوم (أول سؤال، والسلسلة، واتسجّلت) و«مراجعاتي».
- **المقاسات:** 1280 · 834 · 390 · 320، وكل واحد بالخط العادي وبالخط 125%. تقدر تحدّد: `WIDTHS=1280,390 TEXT=md ONLY=exam,boss`.
- **ثابت:** الساعة متثبّتة، والحركة مقلّلة، وكل لقطة بتستنى الأنيميشن يخلص وبتطلع لأول الصفحة. نفس الـbuild بيطلّع نفس الصور.
- **الحالات الغالية بتتبني مرة واحدة:** بيانات العرض، ووحدة متخلّصة دروسها، ومتدرب اتعتمد — وكل مقاس بيبدأ منها.
- **كل لقطة بتتقاس:** الـscroll الأفقي، ونسبة الحروف AAA، والحروف تحت AA، والخط اللي برّه السلّم، وعدد العناصر الدهبي (مقسوم: دهبي «لون» زي الأزرار والتقدّم، و«حافة» #8D6C1A على الحقول والأزرار المحدّدة، ومعاه أسماء العناصر في `goldSamples` عشان كل واحد يتراجع على دوره)، والأزرار المقصوصة، والأهداف الصغيرة، ونتيجة axe (serious وcritical بس).
- **`visual:compare`** بيطلّع صورة قبل/بعد لكل لقطة وجدول `metrics.md` بالفرق.
- النتايج في `visual-out/` (متجاهَل في git). الدليل ما بيتعملش commit.
- `DIST=dist-base` بيعرض build تاني (مثلاً build الـbaseline) من غير ما يلمس `dist/`.

## 2) الدين التصميمي: `scripts/design-debt.mjs`

```bash
npm run design-debt              # العدّ الحالي جنب الـbaseline
npm run design-debt -- --write   # نزّل الـbaseline لما الأرقام تقل
```

بيعدّ: الـinline styles، و`!important`، والوصول المباشر للـpalette (في المكونات وفي الـCSS)، والدهبي المكتوب كقيمة، وكل استخدام للدهبي، ومقاسات الخط اللي برّه الدرجات التسعة، والمدد المكتوبة كأرقام، والأيقونات اللي مش معدّية على `<Icon>`. الاختبار `src/ui/__tests__/designDebt.test.ts` بيقع لو أي رقم طلع فوق `scripts/design-debt.baseline.json`. الرقم ممكن يفضل زي ما هو مؤقتًا، أو ينزل. عمره ما يطلع.
