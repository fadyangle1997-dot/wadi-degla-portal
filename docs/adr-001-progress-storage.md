# ADR-001 — معمارية تسجيل التقدّم (Progress Storage)

**الحالة:** معتمد · **التاريخ:** Phase 1.5 · **المالك:** هندسة المنصة

## السياق
التخزين الحالي snapshot-only في localStorage: بيحفظ «أفضل نتيجة» ويرمي التاريخ (محاولات، توقيتات، أخطاء). لوحة المدرب (Phase 4) والمدير (Phase 5) محتاجين التاريخ ده، والـbackend (Phase 7) هيحتاج مزامنة. القرار لازم يتاخد **قبل** أي feature جديدة — أي تأجيل = بيانات متدربين ضايعة بلا رجعة.

## الخيارات

| المعيار | 1) Snapshot فقط (الحالي) | 2) Backend Interface + سجل أحداث خفيف ✅ | 3) Event Sourcing كامل |
|---|---|---|---|
| التعقيد | أدنى | منخفض (reducer واحد نقي) | عالي (replay، versioned reducers، migrations) |
| الأداء | ممتاز | ممتاز (snapshot مشتق عند الكتابة، القراءة من الـsnapshot) | جيد (لكن replay عند النمو يحتاج snapshots دورية) |
| الصيانة | سهلة لكن **مقفولة** | سهلة — نقطة دخول واحدة | مكلفة — بنية تحتية كاملة |
| التوسع | ❌ يرمي المعلومات | ✅ التاريخ محفوظ، الـbackend لاحقًا = إرسال الأحداث | ✅ الأقصى، لكن فوق الحاجة |
| تكلفة الآن | صفر | **ساعة عمل** | أيام |
| تكلفة مستقبلًا | **إعادة كتابة + فقدان بيانات** | شبه صفر (تبديل adapter) | صفر لكن دفعنا ثمنه بدري بلا داعٍ |
| Trainer Platform | ❌ مفيش «مين اتعثر فين» | ✅ الأحداث فيها كل الإشارات | ✅ |
| Manager/Analytics | ❌ | ✅ (تجميع فوق الأحداث) | ✅ |
| Backend لاحقًا | إعادة تصميم | ✅ `RemoteBackend` يبعت نفس الأحداث | ✅ |

## القرار: الخيار 2
**`ProgressBackend` interface** كنقطة الدخول الوحيدة للتسجيل، بأحداث typed (`LESSON_STARTED`, `LESSON_COMPLETED`, `EXAM_SUBMITTED`, `BOSS_FINISHED`, و`DECISION_LAB_COMPLETED` محجوز). التنفيذ الحالي `LocalStorageBackend`: **يُلحق الحدث بسجل append-only ويشتق الـsnapshot بreducer نقي** ويخزّن الاثنين. القراءة دايمًا من الـsnapshot (أداء)، والتاريخ محفوظ (المستقبل).

**ليه مش الخيار 3:** لا يوجد مستهلك فعلي للـreplay اليوم؛ Event Sourcing الكامل يضيف versioning/migration machinery بدون عائد حالي — over-engineering صريح. الخيار 2 بيدينا 90% من القيمة بـ10% من التكلفة، **ومسار ترقية نظيف** للخيار 3 لو احتجناه (الأحداث موجودة أصلاً).

## العواقب
- الشاشات لا تعرف التخزين — بتنادي دوال دلالية فقط.
- استبدال localStorage بـREST/DB = ملف adapter واحد.
- فشل التخزين لا يكسر الجلسة (in-memory fallback + إشارة صحة).
