# خطة الـPilot — v1.0

> لا تعميم على المؤسسة قبل pilot ناجح موثّق.

## النطاق
5–10 موظفين · 1 مدرب · 1 مدير · 1 مسؤول · على **خادم فعلي** (المزامنة مفعّلة). المدة: أسبوعان.

## الإعداد
1. نشر الخادم + `BACKEND_CONFIG.mode='remote'`. 2. الأدمن ينشئ المستخدمين ويسند مدربًا للموظفين ومديرًا للمدرب. 3. كل مشارك على جهازه (اختبار المزامنة الحقيقي).

## المقاييس (قبل/أثناء/بعد)
| المقياس | المصدر | النجاح |
|---|---|---|
| إتمام التدريب | progress events | ≥ 80% أنهوا الوحدات |
| النجاح من أول مرة | training events | خط أساس يُقاس |
| متوسط الجاهزية | `orgSummary` | ≥ 75% |
| اتساق التقييم | تباين درجات المدرب | منخفض |
| عبء المدرب | عدد التقييمات/الوقت | مستدام |
| مشاكل تشغيلية | `detectOperationalIssues` | تتناقص |
| أخطاء النظام | ErrorBoundary logs | ≈ صفر |
| أخطاء المزامنة | SyncEngine retries | ≈ صفر |
| رضا المستخدم/المدير | استبيان | إيجابي |

## معايير القرار
**نجاح** (تعميم تدريجي): كل المقاييس الحرجة تحققت + صفر خطأ حرج + رضا إيجابي.
**إعادة تقييم:** أي مقياس حرج فشل → عالج → أعد pilot مصغّر.

## بعد الـpilot
جمع الملاحظات → إصلاحات → تعميم على دفعات (فرع فرع)، مش كله مرة واحدة.
