# أدلة المستخدمين — v1.0

## دليل المتدرب (الموظف)
تدخل المنصة أول مرة → شاشة ترحيب توضّح رحلتك → تبدأ أول درس. كل درس: سؤال حقيقي → توقّعك → القاعدة → مثال حي → تمرين → اختبار سريع. بعد إتمام دروس الوحدة → امتحان الوحدة. **مهم:** عدّي الامتحان لا يفتح الوحدة الجاية وحده — لازم مدربك يعتمد أداءك العملي. تقدّمك محفوظ على جهازك (ومتزامن عند تفعيل الخادم).

## دليل المدرب
`#/trainer`. صفحتك الرئيسية «محتاجين انتباهك النهارده» = وحدات عدّت امتحانها ومستنية تقييمك. اضغط «قيّم» → 7 أبعاد (بمؤشر جاهزية حي) → حدّد مهارات/قواعد ضعيفة → المنصة ترشّح دروس المراجعة تلقائيًا → «اعتماد» يفتح الوحدة الجاية، أو «يحتاج تحسين» يفتح الدروس المحددة للمتدرب ويمدّد التدريب. تقدر تضيف ملاحظة توجيه لأي موظف.

## دليل المدير
`#/manager`. لوحة تنفيذية بلا scroll: مؤشر الجاهزية + الثقة + فعالية التدريب، توزيع صحة الموظفين، ومشاكل المحتوى المكتشفة تلقائيًا (أصعب وحدة/قاعدة). «جودة التدريب» تكشف أي مدرب محتاج دعم. اضغط أي موظف لـtimeline كامل. **تذكّر:** ده تقييم جودة تدريب، مش محاكمة أشخاص.

## دليل المسؤول (الأدمن)
`#/admin`. 4 تبويبات: **لوحة التشغيل** (صحة دفتر المستخدمين وتغطية الإسناد) · **الوارد التشغيلي** (المشاكل اللي تتصلّح النهارده، مرتّبة بالخطورة — المنصة بتوجّهك) · **المستخدمون** (إنشاء/تعديل/أدوار/إسنادات/أرشفة) · **سجل التدقيق** (مين عمل إيه ومتى، بفلاتر). الأرشفة لا تحذف أبدًا.

## دليل الدعم / الاستجابة للحوادث
- **متدرب فقد تقدّمه:** تأكد إنه على نفس الجهاز/المتصفح (قبل الخادم)؛ بعد الخادم، تأكد من المزامنة.
- **مدرب مش شايف متدرب:** قبل الخادم = قيد الجهاز الواحد المعروف؛ بعده = افحص المزامنة.
- **بانر «الحفظ مش شغّال»:** localStorage ممتلئ/محظور — الجلسة تكمل في الذاكرة؛ بلّغ المتدرب يحفظ بسرعة.
- **خطأ غير متوقع:** ErrorBoundary يعرض شاشة تحديث؛ لو تكرر، جمّع رسالة الـconsole وبلّغ الهندسة.
