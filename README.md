# أكاديمية عمليات وادي دجلة (Wadi Degla Operations Academy)

منصة تدريب enterprise لموظفي مكتب العضويات. مبنية على مبدأ: **المحتوى بيانات، والقواعد معزولة، والكود بيتبع التوثيق**.

## التشغيل
```bash
npm install
npm run dev        # تشغيل محلي
npm run test       # اختبارات محرك القواعد (لازم كلها خضراء)
npm run typecheck  # فحص الأنواع (strict)
npm run build      # بناء للنشر (dist/)
```

## البنية
- `src/domain/rules/` — محرك القواعد المالية (معزول + متختبر). **مصدر الحقيقة للحسابات.**
- `src/domain/types/` — الأنواع القوية.
- `src/content/modules/` — المحتوى كبيانات (دروس/أسئلة).
- `docs/ARCHITECTURE.md` — القرارات المعمارية.
- `docs/business-rules.md` — قواعد العمل المعتمدة (متطابقة مع الاختبارات).

## قاعدة ذهبية
بعد كل تسليم: **احفظ فولدر `src` عندك** (مش بس ترفع dist). المشروع قابل لإعادة التوليد من `docs/`.
