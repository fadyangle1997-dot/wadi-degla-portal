# أكاديمية عمليات وادي دجلة (Wadi Degla Operations Academy)

منصة تدريب لموظفي مكتب العضويات. المبدأ اللي اتبنت عليه: **المحتوى بيانات، والقواعد معزولة، والكود ماشي ورا التوثيق**.

**النسخة:** 7.28.0. نموذج أولي جاهز لاختبار الإدارة. بيشتغل كله في المتصفح، والخادم لسه في مرحلته الأولى (راجع [ADR-005](docs/adr-005-backend-architecture.md)).
**اللي اتغيّر:** [CHANGELOG.md](CHANGELOG.md) · **دليل تجربة المنصة:** [docs/DEMO.md](docs/DEMO.md)

## التشغيل
```bash
npm ci
npm run dev            # تشغيل محلي على http://localhost:5173
npm run build          # بناء للنشر في dist/
npx vite preview       # تشغيل نسخة البناء
```

## بوابة الجودة (نفس اللي بيشغّله الـCI)
```bash
npm run lint           # ESLint بصفر تحذيرات
npm run typecheck      # TypeScript strict: الواجهة والخادم وملفات الأدوات
npm run test:coverage  # Vitest مع حد أدنى للتغطية (55% للكل · 90% للـdomain)
npm run build && npm run size   # أقصى حد لأول تحميل 200 KB مضغوط
npm run e2e            # Playwright: كل الأدوار + axe (WCAG 2.1 AA) + CSP + الترجمة
```
محليًا، لو Chromium متثبّت في مكان تاني: `PW_CHROMIUM_PATH=/path/to/chrome npm run e2e`.

## البنية
- `src/domain/` — قلب النظام. دوال نقية من غير React ولا تخزين، والخادم بيشغّلها زي ما هي.
  - `rules/` محرك القواعد المالية، وده **مصدر الحقيقة لكل الحسابات**.
  - `readiness/` محرك الجاهزية، وفيه `evidence.ts` اللي بيحوّل تقييمات الست محطات لأدلة.
  - `identity/` الصلاحيات (RBAC)، ونطاق كل مستخدم، والوصول للشاشات.
- `src/content/` — المحتوى كبيانات: الوحدات والدروس والأسئلة ومعارك Boss.
- `src/app/` — المخازن، ومحوّلات التخزين (localStorage والوضع البعيد)، والترجمة، والجلسة.
- `src/features/` — الشاشات حسب الدور: متدرب، ومدرب، ومدير، وأدمن.
- `src/ui/` — نظام التصميم، والمكوّنات المشتركة، و`theme.css`.
- `server/` — خدمة الـAPI (Fastify + PostgreSQL). المنفّذ منها المرحلة 1 بس: `/health` والـschema.
- `e2e/` — اختبارات Playwright.
- `docs/` — قرارات المعمارية (ADR)، وقواعد العمل، والتشغيل، والأمان، وأدلة الاستخدام.

## قواعد العمل
كل رقم في [docs/business-rules.md](docs/business-rules.md) ليه اختبار في `src/domain/rules/__tests__/`. لو غيّرت رقم، لازم الاختبار يتغيّر ويعدّي.

## حدود النموذج الحالي
- البيانات متخزّنة في المتصفح بس، فكل جهاز ليه بياناته. كل مستخدم ليه سجل منفصل على نفس الجهاز.
- الدخول تجريبي ومتحقق منه في المتصفح. ده باب للعرض، مش حماية. المصادقة الحقيقية (OIDC) هي المرحلة 2 من الخادم.
- راجع [docs/SECURITY.md](docs/SECURITY.md) عشان تعرف إيه المنفّذ وإيه المخطط.
